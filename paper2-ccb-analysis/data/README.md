# Data

The participant dataset is not included in this repository. Data are available from the corresponding author on reasonable request, subject to the conditions of the ethics approval.

To reproduce the results, place the file here as `CCB_Two_Phase_Data.csv` (or the Excel workbook with sheet `Original_Data`). It has 391 matched Time 1–Time 2 cases with these columns:

- Background: `Age`, `Gender_Female`, `Marital_Status_Married`, `Education_Level`, `Total_Experience_Years`, `Tenure_Org_Months`, `Tenure_Supervisor_Months`
- Items (1–5 scale): `CCB_1`–`CCB_5`, `LMX1_1`–`LMX1_7` (Time 1), `LMX2_1`–`LMX2_7` (Time 2), `TP_1`–`TP_5`, `CP_1`–`CP_8`, `CWB_1`–`CWB_5`, and the IPIP-NEO conscientiousness facets `SE_1`–`SE_10`, `OR_1`–`OR_10`, `DU_1`–`DU_10`, `AS_1`–`AS_10`, `SD_1`–`SD_10`, `CA_1`–`CA_10` (already reverse-keyed where required)
